# Dosti Khata

Aizaz aur Abdullah ka saanjha hisaab. React + Vite (PWA) frontend, Express + MongoDB backend.

## Env vars
- `MONGODB_URI`: MongoDB connection string (na ho to local `data/entries.json` use hota hai)
- `APP_PIN`: app kholne ka PIN
- `APP_SECRET`: koi bhi lamba random text
- `PERSON_A`, `PERSON_B`: naam (default Aizaz, Abdullah)

## Chalana
```
npm install
npm run build
npm start
```
Development: `npm start` aur doosre terminal mein `npm run dev`.
